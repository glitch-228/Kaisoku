These compact RAR fixtures come from Junrar v8.1.1's test suite:

https://github.com/junrar/junrar/tree/v8.1.1/src/test/resources/com/github/junrar

Junrar and these upstream fixtures are distributed under the project's UnRAR
license; see https://github.com/junrar/junrar/blob/v8.1.1/LICENSE. The fixtures are
included only in the JVM test source set and are not packaged in Kaisoku APKs.

`comic-rar5.rar` and `comic-rar5-solid.rar` were generated specifically for
Kaisoku with RAR 7.23 from two 8x8 test images and a `ComicInfo.xml` metadata file.
`invalid-image.rar` was generated the same way from a deliberately invalid `.jpg`.
